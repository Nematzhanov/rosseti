# Сайты проекта

## 1. Сайт с результатами — `dashboard/nw-load-forecast.html`

Открывается в любом браузере, сервер не нужен. Все данные встроены в страницу:
сравнение моделей, неделя «факт/прогноз», ошибка по месяцам, календарь ошибок, связь с температурой, информация об авторе.
Пересобрать после нового расчёта: `.venv/bin/python model/export_dashboard.py`.

## 2. Сайт с прогнозированием — `webapp/`

Интерфейс «Сделать прогноз»: выбираете сутки и модель, нейросеть Chronos-2 считает почасовой прогноз
(с докачкой свежих данных СО ЕЭС и прогноза погоды Open-Meteo).

```bash
python3 webapp/server.py        # затем открыть http://localhost:8790
```

Нужны окружение `.venv` (см. `requirements.txt`) и веса модели в `checkpoints/`
(в репозиторий не входят из-за размера: получаются запуском `model/train_chronos.py --runs lora`).

## 3. Настольное приложение — `gui/`

То же на Java Swing: `./gui/run.sh`.
